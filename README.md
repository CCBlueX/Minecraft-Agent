# Minecraft Agent site

Generator for [ccbluex.github.io/Minecraft-Agent](https://ccbluex.github.io/Minecraft-Agent/): plain HTML from the `main` branch's README and
skill, its Dokka API docs, and the AI usage card drawn from `ai-usage/`.

`./gradlew run --args="--main <main checkout> --api <Dokka HTML folder or none> --out <folder>"`
